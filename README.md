# Watery Water Sort

Android-игра сортировки жидкостей. Планируемый первый магазин — RuStore.

Стек по ТЗ: TypeScript + Phaser + Vite + Capacitor, нативная реклама Яндекса.

## Текущее состояние

Полировка 0.22: 16 уровней, большая цветная цель на 8 порций, переливание с наградой в момент наполнения, материальные семплы воды/стекла/пробки, цветные фонтаны на победе, сбор звёзд в общий прогресс, трёхфазное заполнение и усиленная вибрация, последовательные хлопки и частицы по всему экрану, отмена, сохранение, Worker-подсказки, четыре цветовые темы/символы и Android-оболочка. Дополнительная колба открывается через rewarded; debug APK использует демоблок Яндекса. Подсказки без лимита. Не готово к магазину.

## Запуск

Node 22+, затем:

```sh
npm ci
npm run dev
npm test
npm run build
npx playwright install chromium
npm run test:e2e
```

Android: JDK 21 и SDK 36, `npm run android:sync`, затем `cd android && ./gradlew assembleDebug`. GitHub Actions выполняет проверки и сохраняет debug APK как `watery-water-sort-debug`. Релизной подписи нет.

`npm run levels` воспроизводит исходный прототипный банк. Не перегенерировать выпущенные задачи без новой версии и миграции.
