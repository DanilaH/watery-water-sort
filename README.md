# Watery Water Sort

Android-игра сортировки жидкостей. Планируемый первый магазин — RuStore.

Стек по разбору ТЗ: TypeScript + Phaser + Vite + Capacitor, нативная реклама Яндекса.

## Документация

- [Роудмапа v1](docs/ROADMAP.md) — этапы, критерии готовности, предлагаемые решения и открытые вопросы.
- Исходное исследование и полное ТЗ: ожидают переноса в `docs/source/`. Сводка из чата не заменяет оригиналы.

## Текущее состояние

Подготовлен рабочий план. Реализация ещё не начата. Первый результат — APK с 10–15 уровнями, законченным переливанием, звуком, отменой и сохранением; после проверки — полный банк из 100 уровней.
