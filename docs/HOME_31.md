# Живое главное меню — 0.31

Колбы независимо покачиваются и парят, жидкость реагирует волной, по ней проходят мягкие блики. Период 7.2 секунды; синусоидальные фазы непрерывны, блик возвращается в начало за пределами жидкости. Объём слоёв сохраняется существующим area-corrected liquid mesh; соседние цвета имеют общий контур. Одинаковый цвет в центральной колбе объединён в один слой, без искусственного шва.

Используется прежнее стекло tube-27.webp: три SVG-среза на колбу, без дополнительных bitmap assets и без отдельного DOM canvas. Все слои остаются под стеклом. Обновление не чаще 30 Hz.

Главное меню явно получает lifecycle из paint(): RAF отменяется в игре, за диалогом, при pagehide, document.hidden и native background. Возобновление с той же фазы, без учёта фонового времени. Reduced motion — неподвижная композиция без бликов, live изменение настройки поддерживается. Геометрия интерфейса и области нажатия не анимируются.

Проверки: два браузерных сценария движения/сохранения/паузы/возобновления и reduced motion; существующие navigation/themes. Реальная GIF-запись и итоговый CI/APK — audits/home-31.
