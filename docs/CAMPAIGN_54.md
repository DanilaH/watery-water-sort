# Кампания 0.54

50 раскладок переработаны, 40 добавлены после прежнего финала. Десять ранних задач оставлены, чтобы сохранить обучение и передышки. Порядок и идентификаторы первых 60 не меняются. С 18-го уровня встречаются шесть цветов, в конце — семь. Сложность создают ограниченный буфер, порядок переливов и комбинации существующих механик: больших приёмников, мини-колб, льда и скрытых слоёв. У новых больших приёмников нужный цвет виден сразу.

Каждый уровень решается без усилителей. Порог трёх звёзд рассчитан по кратчайшему пути, который проверяет независимый перебор. Один дополнительный сосуд тестируется отдельно. Жадный бот используется только для отбора раскладок, его результаты не оценивают реальную проходимость игроками.

Продолжение и перезапуск сохранённой попытки сохраняют старую раскладку. Явный выбор уровня открывает новую. Рекорды, звёзды и монеты сохраняются. После старого финала открывается 61-й этап.

- `tools/balance-campaign-54.ts` — генерация из архива с фиксированным сидом и бюджетом в узлах.
- `npm run ratings:generate` — точные маршруты и независимая проверка оптимальности.
- `npm run ratings:check` — сверка исторических и текущих порогов и маршрутов.
- `python3 tools/audit-campaign-54-fingerprints.py` — проверка физически одинаковых полей с точностью до переименования цветов и перестановки обычных колб.
