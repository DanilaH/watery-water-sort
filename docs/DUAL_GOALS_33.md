# Две большие цели · 0.33

Первый пакет из исследования механик конкурентов: две принимающие колбы разных цветов, шесть новых уровней (17–22). Мини-колба, лёд и скрытые слои остаются следующими отдельными пакетами.

## Правила и прогресс

Каждая большая цель принимает восемь порций только своего цвета и не используется как источник. Обе должны быть заполнены; третий цвет, когда он есть, собирается в обычной колбе. Четыре порции целевого цвета в обычной колбе не считаются завершённым цветом. Завершение первой цели не завершает уровень.

Старые 16 уровней, их идентификаторы, версии и рейтинги сохранены. Старое поле `goal` продолжает поддерживаться; новые уровни используют `goals`. Формат сохранений не меняется. История проверяется повторным применением правил с обеими целями, лучший результат сохраняется после отмены. Дополнительная рекламная колба обычная; уровни с двумя цветами по-прежнему без рекламного слота.

Подсказки сохраняют отдельную идентичность каждой цели, канонизируют только обычные колбы. Отмена переливания в любую из целей не поднимает высокую колбу.

## Оформление

Цели располагаются по краям банка и совпадают верхом и низом с крайними рядами обычных колб. Для каждой предусмотрены независимое основание, разлетающиеся фрагменты, три усиленных тактильных этапа заполнения, пробка и финальный цветной фонтан. При уменьшенном движении основание затухает без разлёта. Метки различают целевые цвета; описание цели обновляется после заполнения одной из колб. Общая победная анимация остаётся с перекрывающимися эффектами.

## Уровни

| Уровень | Задача | Минимум без / с дополнительной колбой |
| --- | --- | --- |
| 17 | Две цели, открытые группы для знакомства | 6 / 6 |
| 18 | Два цвета в чередующихся слоях | 12 / 12 |
| 19 | Третий цвет перекрывает часть целевых слоёв | 14 / 14 |
| 20 | Распределённый третий цвет и короткие группы | 19 / 19 |
| 21 | Более плотное чередование трёх цветов | 20 / 20 |
| 22 | Более лёгкое закрепление после сложного уровня | 18 / 18 |

Это фиксированные авторские раскладки. Равенство оптимумов с рекламной колбой не означает отсутствие помощи: буфер расширяет доступные промежуточные состояния и позволяет исправлять ошибки. Минимумы не снижались искусственно ради рекламы.

## Проверка

`docs/audits/dual-goals-33/optimal.json` содержит все 44 оптимальных пути для 22 уровней с рекламной колбой и без. C++ A* сохраняет фиксированный префикс обеих целей и сортирует только обычные колбы; отдельный Python-поиск с собственными переходами подтверждает отсутствие более коротких путей и повторяет каждый найденный путь. Рабочий TS solver используется только для подсказок, а не как доказательство оптимальности.

Проверки правил включают неправильный цвет/цель, дубли целей, произвольные индексы обеих целей в solver, все новые пути через сохранение, отмену и перезапуск, сохранение объёма и матрицу непересекающихся областей нажатия от 48 px. Браузерные сценарии проверяют обе цели, реальный Worker, тяжёлые этапы заполнения, отдельные основания, рекламу, восстановление, повторный выбор уровня и финал на 320×480, 390×844, 568×320.

На физическом телефоне эта версия пока не проверялась. Браузерная демонстрация без звука не доказывает качество нативной вибрации.
