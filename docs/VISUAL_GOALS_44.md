# 0.44 — цель видна по жидкости, меньше надписей

## Поведение

На новом старте каждого из 24 уровней с большими приёмниками внутри каждого
приёмника уже есть жидкость его цвета. Для двух приёмников видны оба цвета.
Это настоящая жидкость из раскладки, а не декоративная полоса: один доступный
верхний слой переносится в соответствующий приёмник. Берётся наименьшая
доступная группа, при равенстве — первая колба по индексу. Дополнительная жидкость
не создаётся, вместимость приёмников остаётся 8.

Игрок начинает с 0 ходов. Отмена доступна после первого собственного хода и не
может убрать стартовый запас. Новая попытка, выбор уровня и «Дальше» используют
этот старт. Продолжение уже сохранённой партии не переставляет её жидкость.
Открытая рекламная колба, память скрытых слоёв, монеты, прежние результаты и
рекорды сохраняются.

## Баланс и совместимость

Исходный банк уровней и стабильные ID/версии сохранены. Начальное заполнение
хранится как детерминированный префикс replay с полем `setup` (1 или 2) у новой
попытки и нового рекорда. В интерфейсе и аналитике учитываются только ходы игрока;
звёзды сравниваются по прежней общей шкале, включая префикс. В справке пороги
показаны уже без стартовых ходов. Результаты старой и новой раскладки остаются
сопоставимыми, ранее выданные монеты не начисляются повторно.

Пересчитаны точные оптимумы всех 60 уровней, с дополнительной колбой и без неё.
Для всех 120 вариантов: `новый оптимум + setup = прежний оптимум`.
Для 24 затронутых уровней осталось на 1 или 2 хода меньше. Это не оценка
субъективной сложности: первый ход упрощён намеренно, скрытые слои, открытые этим
стартом, действительно становятся известны. Остальные правила не меняются.

Новые оптимальные маршруты включены в Worker-подсказки. Старые маршруты также
оставлены для продолжаемых старых партий. Поиск после произвольных отклонений
по-прежнему ограничен временем; оптимальность любого произвольного состояния
не обещается.

Проверки:

- `npm run ratings:check`: независимая Python-реализация получает новые старты,
  сверяет сохранение общей шкалы, затем доказывает отсутствие более короткого
  решения для каждого из 120 вариантов. Исходные 120 доказательств тоже остаются.
- `tests/goal-start.test.ts`: сохранение объёма, 0 ходов игрока, граница Undo,
  легальность и победа всех 120 путей, оптимальные начальные подсказки, старые
  сохранения и выдача монет без повторного начисления, проверка метаданных setup.
- `tests/browser/visual-goals44.spec.ts`: реальные экраны с одной/двумя целями на
  320×480, 390×844 и 568×320; выбор уровня, reload, Undo, подсказка, пороги звёзд,
  карта и экран победы. Прежние тесты явно продолжают старые сохранения и проверяют
  новый старт при выборе/повторе уровня.

## Разбор надписей

| Экран / ситуация | Решение | Причина |
|---|---|---|
| Цвет большой колбы | Убрана инструкция «Собери ... жидкость...» | Цвет задаёт реальная жидкость внутри |
| Большая колба заполнена | Убрано «Большая колба готова · собери остальные цвета» | Заполнение и эффект завершения показывают это сами |
| Мини-буфер | Убрана постоянная инструкция оставить его пустым | Сохраняется визуальная маленькая вместимость; победа проверяет правило |
| Карточки уровней | Убраны «Большая цель», «Две цели», «Цель + мини», «Мини-колба», «Лёд» | Дублировали механику вместо полезной навигации; доступные названия сохранены в aria-label |
| Карточки уровней | Убраны рекорды в ходах | Список теперь показывает номер, звёзды и особую сложность |
| Обычный выбор колбы после обучения | Убрано повторение правила каждого перелива | Подъём колбы и подсветка подходящих целей дают обратную связь |
| Главное меню | Оставлен номер текущего уровня, убраны ходы | Ходы нужны в самой партии |
| Победа | Убраны повтор ходов и подпись рекорда под заголовком | Ходы уже есть в HUD; акцент на анимации, звёздах и кнопке |
| Над полем | Удалён старый узел общего количества уровней | Он уже скрывался CSS; не считается видимым улучшением |
| «Сложный уровень» | Оставлен | Заранее задаёт ожидание; это отдельно запрошенная часть оформления |
| Названия кнопок | Оставлены | Отличают отмену от перезапуска, снижают риск ошибки |
| Первый запуск и первый лёд | Оставлено короткое обучение | Условия ещё могут быть неизвестны игроку |
| Подсказка и очередь следующего хода | Оставлено контекстное сообщение | Показывает заказанное действие и возможность отменить очередь |
| Тупик / сбой сохранения / недоступная реклама | Оставлены объяснения | Игроку нужен способ продолжить и причина отказа |
| Подтверждение перезапуска | Оставлено | Защищает от случайного сброса |
| Монеты, пакеты подсказок, rewarded | Оставлены цена, количество и условия | Это осознанный выбор с расходом ресурса или просмотром рекламы |

Полный Android CI и проверенный APK фиксируются в `audits/visual-goals-44/validation.json`
после завершения сборки. Физический плейтест остаётся отдельной проверкой.
