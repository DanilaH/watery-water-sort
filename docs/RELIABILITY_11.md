# Исправления после независимого разбора — 0.11

Версия Android: 11 / 0.11.0-reliability. Пакет preview3 и публичный тестовый сертификат сохранены: обновление поверх предыдущей сборки сохраняет локальный прогресс.

## Изменения

- Capacitor core/android/cli согласованно обновлены с 8.0.0 до исправленной ветки 8.4.3. Уязвимый внутренний HTTP proxy закрыт upstream. Выбрана 8.4.3 вместо 8.5.3: у последней npm audit показывает дополнительную цепочку xcode → uuid в CLI. Плагин App остаётся совместимым 8.0.0.
- Vite 7.3.7 и Vitest 4.1.12. Переход только на Vitest 3.2.7 оставлял уязвимые mocker/tinypool, поэтому обновлён весь тестовый runner. Без принудительных overrides несовместимых транзитивных библиотек. Свежий npm audit: 0 уязвимостей, включая devDependencies. Dev-сервер по умолчанию слушает только localhost.
- Сбой создания AudioContext или его начального графа больше не прерывает main.ts. Игра стартует, настройки открываются, ходы сохраняются. При выключенном звуке AudioContext не создаётся. После временного отказа следующий жест может повторить инициализацию.
- На 320×480 при 11 колбах поле использует дополнительные боковые 14 px с каждой стороны. Шесть колонок и два ряда вместо трёх: видимая колба 26.5×95.5 вместо 18×58.3. Зона нажатия 48×105.5, соседние зоны не пересекаются. При 10 колбах раскладка прежняя. На большом портрете и landscape геометрия сохраняется.
- Короткий текст помощи и компактнее вертикальные отступы landscape-диалога: на 568×320 объяснение читается без прокрутки, все три действия остаются высотой 48 px.

## Проверка

23 теста ядра. Браузерный набор расширен с 53 до 57: отказ аудиоустройства при sound=true/false с ходом и reload; реальное добавление одиннадцатой колбы и ход в неё; отсутствие прокрутки текста маленького landscape-диалога. Финальный набор после обновления всех зависимостей прошёл 57/57; CI повторяет проверки перед сборкой APK.

Повторный независимый runtime-пробник: оба отказа аудио дают canvas=1, settingsOpen=true, errors=[]; дополнительная колба, muted reload и hint продолжают работать. Подробные результаты и снимки — `docs/audits/fixes-11/`.

Физический Android, реальная задержка звука/вибрации, сворачивание и возврат приложения на телефоне здесь не проверялись. Стандартная нативная иконка и splash остаются отдельной задачей оформления; это обновление закрывает три главных технических замечания и текст помощи. Механику, уровни, звуковые семплы и баланс не меняли.
