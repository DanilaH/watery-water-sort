# Экономика, подсказки и реклама — 0.42

2 ноября 2026. Исходная версия: d7694b1 / 0.41. Пакет сохраняет игру, материалы жидкости, звук переливания, 60 уровней и сохранения preview3.

## Правила

- Новая звезда: 10 монет. Только увеличение максимума по стабильному ID уровня; перепрохождение, Undo и перерисовка не фармят монеты. Старые доказанные результаты и старые completion-only записи мигрируют один раз (completion-only = одна звезда).
- Старт: 0 монет, 3 подсказки; все шесть двухцветных уровней имеют бесплатные подсказки.
- Пакет: 3 подсказки за 60 монет. Награда за один добровольный rewarded: 80 монет. Покупка отдельно подтверждается после пополнения; просмотр сам ничего не покупает.
- Undo, Restart и четыре текущие темы бесплатны. Дополнительная колба по-прежнему отдельный rewarded, одна на уровень/версию, с сохранением при перезапуске.
- Баланс, запас, начисленные звёзды, активное рекламное предложение и обработанные монетные receipts входят в существующий атомарный снимок сохранения. Нативный receipt подтверждается после сохранения эффекта. Повторный receipt не платит второй раз. Не удалять dedup токены при изменении будущего формата без сохранения его гарантий.
- coins:<UUID> — неизменяемое предложение версии 1: 80 монет. Если в будущем поменяется награда, старые targets должны продолжать выдавать 80, новая сумма требует нового SKU/версии; нельзя интерпретировать старую награду по новым ценам.
- При двух отказавших хранилищах и убийстве процесса серверной гарантии восстановления нет. Резервная копия может восстанавливать более старый снимок; локальный кошелёк не является серверной защитой от изменения/отката сохранения.

## Подсказки

Проверенный независимым offline-поиском банк 120 оптимальных решений перенесён из docs/audits/campaign-39/optimal.json в src/core/optimalRoutes.json. Индексы бутылок/состояние льда проверяются точным совпадением поля и правил; после отклонения используется ограниченный IDA* поиск с допустимой оценкой числа цветовых серий минус число цветов и безопасным DFS fallback. Полный исходный маршрут по банку даёт три звезды во всех 120 конфигурациях; произвольное состояние не получает обещания трёх звёзд, если они уже недостижимы или ограниченный поиск не доказал оптимальность.

Скрытые слои не раскрываются решателем: пока они есть, совет ранжируется по видимым цветам и явно описан как такой в окне покупки. Это не обещание идеального прохождения. Ошибка/таймаут/отсутствие найденного хода не списывает подсказку. Повтор текущего сохранённого совета на том же состоянии поля бесплатен и переживает reload. Следующий совет заменяет предыдущий; полный архив всех когда-либо купленных советов не хранится.

## Реклама

Баннер: нативный adaptive sticky, DOM-slot в обеих ориентациях. Слот нейтрален и остаётся зарезервированным при no-fill/диалоге. Размер SDK → достаточная CSS-высота → повторный замер → attach. Маппинг по реальной ширине WebView, не DPR; inward округление, safe insets, offsets, padding и вертикальное центрирование. Баннер скрыт в меню, на первых двух этапах, в диалогах, при background/fullscreen. SDK владеет auto-refresh; ручного цикла refresh нет. Ошибка допускает новый load только при следующем обращении к размещению спустя 30 секунд.

Interstitial: только явное «Дальше» после сохранённой победы, начиная с третьего этапа, после прохождения первых двух. Перепрохождение участвует. Нет лимита в час, нет требования трёх новых побед. Интервал 60 секунд после закрытия полноэкранной рекламы. Возможность показа расходуется даже при no-fill: повтор не чаще 60 секунд. Нет готового объявления — немедленный переход; поздняя загрузка никогда сама не открывает рекламу. Прелоад ограничен одним объявлением и backoff. Нативная общая блокировка не допускает совместного rewarded/interstitial; баннер скрывается на время fullscreen. Предзагрузка имеет deadline, показанное SDK-окно не разблокируется таймером.

Производственная упаковка требует три реальных Yandex ID, ключ аналитики и непубличную подпись. Debug использует demo-banner-yandex, demo-interstitial-yandex и demo-rewarded-yandex; analytics API key пуст. Live доставка, fill и реальные ощущения требуют проверки телефона.

## Расчёт стартовой конфигурации

60 уровней дают максимум 180 звёзд / 1800 монет. При всех результатах в 1/2/3 звезды бюджет — 600/1200/1800 монет, или 33/63/93 подсказки с учётом трёх стартовых. Эти числа не включают рекламное пополнение.

Последовательная модель: шесть двухцветных уровней не расходуют запас, остальные 54 требуют 1, 2 или 4 совета; покупка до победы, начисление после неё. При двух звёздах каждый раз нужно 0/12/39 rewarded за монеты, при трёх — 0/5/32. Это сценарии, а не прогноз конверсии/дохода; нет расходов на темы и rewarded за колбы. Конфигурация — гипотеза для измерения, не рыночный оптимум.
