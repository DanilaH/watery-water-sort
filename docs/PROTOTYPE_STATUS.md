# Первый прототип — 23.10.2026

> Исторический протокол 0.1. Графика и звук отвергнуты владельцем после APK-проверки. Текущая переработка — [FEEL_REVISION_02.md](FEEL_REVISION_02.md).

## Реализовано

- Чистые правила переливания верхней группы, проверка победы, неограниченная отмена и повтор той же задачи.
- 12 воспроизводимых стартов на 2–8 цветов. Каждый путь проверяется генератором и отдельным тестом воспроизведения. Это кандидаты для плейтеста, не утверждённая прогрессия.
- Состояние записывается до анимации; web-сохранение с проверкой истории и резервной копией. Ошибка записи не принимает ход. При двух повреждённых копиях нужен явный выбор нового старта.
- Переливание 540 мс / ускоренное 300 мс; горизонтальная поверхность жидкости при наклоне с сохранением площади; струя и брызги синхронизированы с переносом группы. Одно видимое намерение следующего хода, повторная проверка перед исполнением.
- Собственные процедурные SFX: выбор, отказ, вариативное журчание, колба, победа, подсказка. Один AudioContext, до 4 голосов, остановка в фоне и при прерывании. Восприятие тембра на телефоне ещё не подтверждено.
- Две темы, символы, настройки скорости/звука, портрет/альбом, резерв места дополнительной колбы и баннера.
- Решатель в Worker, отмена устаревшего запроса, FOUND/UNKNOWN/UNSOLVABLE; подсказка относится к текущему полю.
- Capacitor Android-проект; Back/foreground события. Автоматическая сборка debug APK через GitHub Actions.

## Выполненные проверки

- TypeScript + production web build — проходят.
- 12 unit/integration tests — проходят. Включают 2000 детерминированных ходов с инвариантами и обратимостью, все 12 свидетелей решения, ограниченный поиск, невозможную позицию, повреждение сохранений, отказ записи, сохранение дополнительной колбы через Undo/Restart, геометрию жидкости.
- 2 Playwright-сценария — проходят: полное прохождение первого уровня; перезагрузка во время переливания и Undo после неё; подсказка, символы, скорость, темы; границы экрана 320×568, 844×390, 768×1024.
- Визуально просмотрены Chromium-кадры: старт 390×844, середина переливания, восьмицветное поле на 320×568 и 844×390. Исправлены горизонтальное переполнение и обрезание финального звука окном победы.
- Проба решателя: 200 позиций на известных путях уровней с 6–8 цветами, 200 FOUND, 0 UNKNOWN, host Node p95 ≈0.87 мс. Это повторяющиеся префиксы witness, не независимый корпус человеческих позиций и не измерение телефона. Критерий роудмапы этим не закрыт.

## Не готово / не доказано

- Реальная нативная реклама и reward journal, дневные квоты/кредиты подсказок, аналитика, vibration/audio focus. В прототипе подсказки без лимита, дополнительная колба недоступна; меню сообщает об этом.
- Crash durability Android localStorage, реальный поворот Activity, доступность WebGL после потери контекста и native audio focus ещё требуют отдельных Android-проверок.
- Телефонные p95 отклика/60 fps/нагрев, 20-минутное прослушивание, плейтест пяти людей, сравнение с установленными конкурентами не проводились.
- 100 уровней, калибровка сложности, оригинальная иконка, релизная подпись и материалы магазина не готовы. Рабочее имя — «Переливы».
- CI/наличие APK не означает, что приложение проверено на физическом устройстве. Статус Android build смотреть в Actions конкретного коммита.

Следующий приоритет: установить debug APK, проверить ввод и переливание со звуком на устройстве; устранить ощущения задержки/пластмассового звука/нечитаемости до расширения контента. Параллельно довести нативные платформенные адаптеры по ТЗ.
