# VFX 0.24

`normal.webp`, `goal.webp`: реальные production-кадры с новыми брызгами. `*-capture.json`: хеши оригинальных compositor PNG и всех production-файлов, настоящие временные метки. `*-gif.json`: отбор кадров и интервалы GIF, без интерполяции. `before-*`: настоящая 0.23 для сравнения.

[Отчёт, ассеты, промпт и ограничения](../../VFX_24.md). Генерация создала сами формы; цвет и движение задаёт игра. Изображения atlas на прозрачном фоне; проверены на синем фоне.
