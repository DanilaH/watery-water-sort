# Движение жидкости 0.22

`liquid-motion.gif`: реальные compositor PNG-кадры с их временными интервалами, без интерполяции; только кадрирование игрового поля и преобразование в GIF. `settled.webp`: полный экран после движения. Подробности, ограничения и воспроизведение: [LIQUID_22.md](../../LIQUID_22.md). `capture.json` содержит хеши исходной сборки и оригинальных кадров; `liquid-motion.json` — кадры итогового GIF.
