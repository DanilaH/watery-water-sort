# Пакет 1 — 0.25

Реальные кадры и данные проверки движения внутренних слоёв, обычного завершения цвета и большой цели. `*-capture.json` содержит временные метки и оригинальные хеши кадров/production-файлов; `*-gif.json` описывает упаковку GIF. `before-capture.json` — независимая запись настоящей 0.24.

[Реализация, проверки и ограничения](../../MATERIAL_25.md). Записи без звука; звук и вибрация на физическом телефоне не оценивались.
